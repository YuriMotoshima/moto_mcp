## Regras do índice

- Menção explícita ou alias identifica o cliente.
- Na ausência de menção, usar o cliente ativo somente quando a continuidade for
  inequívoca.
- Se houver ambiguidade, perguntar qual cliente antes de carregar uma memória ou
  registrar informação.
- Cliente novo exige uma nova linha e um arquivo próprio (`clients/_TEMPLATE.md` como
  ponto de partida), criados na mesma operação.
- Atualizar estado e data quando houver mudança relevante; não registrar detalhe do
  cliente neste índice — só no arquivo dele.
