# Handoff - Review Checklists

## Backend

- Auth/scope/tenant corretos.
- Repositories sem SQL dinâmico inseguro.
- Services com regra de negócio real.
- Schemas validando entrada e saída.
- Logs sanitizados.
- Erros com resposta controlada.
- Testes cobrindo caminho real.

## Frontend

- UI não mostra identificador interno sensível ao cliente sem necessidade.
- Validação de UX não substitui regra do backend.
- Dados dinâmicos não entram como HTML executável.
- Fluxo principal claro para usuário final.

## Marketing

- Escopo proporcional ao negócio.
- Conversão definida e mensurável.
- Promessas comerciais verdadeiras.
- Pendências não viram bloqueio artificial.
